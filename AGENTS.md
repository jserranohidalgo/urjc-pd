# Agent instructions

This repository holds the Jupyter notebooks for a course on Declarative
Programming at URJC. If a student asks for help getting set up or working
with this material, start by reading `README.md` — it has the full
instructions, and answers should stay grounded in what it actually says
rather than inventing steps it doesn't cover.

In particular, help with:

- **Installing and launching notebooks.** See "Launching notebooks" and
  "Installing jupyter and the Scala kernel" in `README.md`. Walk the student
  through installing `git`, `jupyter`, Java, and the `almond` Scala kernel —
  or the Docker alternative described there — and check `README.md`'s list
  of known installation issues before troubleshooting from scratch.
- **The git branch workflow.** See "Git branches" in `README.md`. Help the
  student create a personal branch off their course branch (`MOS-26-27` or
  `VIC-26-27`), commit their in-class work there, and pull the course
  branch's updates afterwards — without committing directly to it.
